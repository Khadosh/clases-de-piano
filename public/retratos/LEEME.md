# Los retratos de /sobre

Tres archivos, todos opcionales — mientras no estén, la página muestra las
iniciales (o el teclado, para el cuaderno):

- `quique.jpg` — el profe
- `joaquin.jpg` — el alumno
- `cuaderno.jpg` — el tercer pianista

Con subirlos acá alcanza: la página mira en el build si existen, así que el
próximo deploy los levanta solo. Se recortan en círculo (object-cover), así
que conviene que el sujeto esté más o menos centrado.
